# 斗地主 AI 项目计划

## 项目目标
训练一个强大的斗地主 AI，能够：
1. 合理叫分（根据手牌强度决定叫 0/1/2/3 分）
2. 智能出牌（理解炸弹规则，知道炸弹可以压一切）
3. 学会配合（农民之间配合对抗地主）

## 核心方法：MCTS + 深度强化学习

### 为什么用 MCTS？
- MCTS 可以评估每个动作的长期价值
- 通过模拟对局，计算胜率
- 让模型学会"这个局面下我的胜率是多少"

### 训练流程
1. 使用 MCTS 进行对局搜索
2. 生成训练数据：(局面, MCTS策略, 胜率评估)
3. 训练神经网络模仿 MCTS 的决策
4. 神经网络学会评估局面和选择最优动作

## 关键设计决策

### 1. 牌组轮换策略
- 每个牌组被 3 个 agent 各使用一次
- 确保公平性，每个 agent 都有机会用同样的牌学习

### 2. 炸弹特征输入
- 神经网络输入包含炸弹特征（5维）
- 让模型明确知道手牌中是否有炸弹
- 特征：是否有炸弹、炸弹数量、最大炸弹点数、是否有王炸、王炸数量

### 3. 奖励设计
- 获胜基础奖励
- 炸弹使用奖励（使用炸弹且获胜额外加分）
- 鼓励模型学习使用炸弹

### 4. 并行训练
- 同时运行多个游戏对局
- 批量处理，提高 GPU 利用率
- 大幅加速训练

## 配置参数（config.py）

### MCTS 参数
- `MCTS_NUM_SIMULATIONS`: 每次决策模拟次数（50-400）
- `MCTS_C_PUCT`: 探索参数（1.0）
- `MCTS_TEMPERATURE`: 温度参数（1.0训练，0.0测试）

### 并行参数
- `PARALLEL_BATCH_SIZE`: 并行游戏数（8）
- `USE_PARALLEL_MCTS`: 是否启用并行

### 训练参数
- `CYCLE`: 总训练轮数
- `H`: 每轮每个 agent 训练局数
- `LEARNING_RATE`: 学习率

## 注意事项

1. **MCTS 很慢** - 必须并行化，否则训练时间过长
2. **炸弹规则** - 确保模型理解炸弹可以压一切
3. **地主补牌** - 补底牌后重新计算炸弹特征
4. **公平性** - 牌组轮换，每个 agent 机会均等
